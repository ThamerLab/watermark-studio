# Watermark Studio

أداة عربية لإضافة العلامات المائية إلى ملفات PDF محليًا داخل المتصفح. لا خادم، لا Docker، ولا رفع للملفات إلى الإنترنت.

## التشغيل

نزّل الملف [watermark-studio.html](./watermark-studio.html)، ثم افتحه بالنقر المزدوج في Microsoft Edge أو Google Chrome. جميع المكتبات والخط العربي مضمنة في الملف نفسه، لذلك يعمل دون اتصال بالإنترنت.

النسخة المحلية تدعم:

- ملف PDF فردي أو مجموعة ملفات PDF.
- نص عربي/إنجليزي متعدد الأسطر، الموضع، اللون، الحجم، الشفافية، الدوران، والتكرار.
- علامة صورة PNG/JPEG في المسار الفردي.
- كل الصفحات، الصفحة الأولى، أو نطاقات مثل `1-3,7,10-12`.
- CSV عام بعمود `watermark_text` المطلوب و`output_name` الاختياري.
- ZIP منظم في مجلد لكل علامة، مع `_manifest.csv` بترميز UTF-8 BOM.

لا تدعم هذه النسخة PowerPoint. حوّل العرض إلى PDF من PowerPoint أو LibreOffice أولًا.

## بناء الملف الواحد واختباره

يلزم Node.js للمطور فقط، وليس للمستخدم النهائي:

```bash
npm ci
npm run build:standalone
npm run test:standalone
```

مصادر النسخة المحلية في `standalone/src/`. ناتج البناء النهائي هو `watermark-studio.html` في جذر المستودع.

## النسخة الخادمية السابقة

ملفات FastAPI وDocker وProxmox السابقة باقية في المستودع للتوافق والرجوع إليها، لكنها ليست مطلوبة لتشغيل النسخة المحلية الجديدة.
